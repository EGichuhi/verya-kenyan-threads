# VERYA Website Plan

## Goal
Create a mobile-first, highly visual homepage that presents VERYA as a confident Kenyan-rooted custom apparel partner for schools, businesses, teams, events, and organizations.

## Build
- Establish a bold design system using only the supplied teal, orange, gold, plum, charcoal, and cream palette.
- Use strong typography, color blocking, subtle textile-inspired patterns, and contemporary African-inspired geometry.
- Build the homepage in the requested order: hero, product showcase, why VERYA, ordering process, founder story, gallery, and bulk quotation/contact section.
- Generate cohesive apparel and textile imagery featuring Kenyan schools, teams, businesses, production, and founders without using the Kenyan flag as the identity.
- Make the quotation form easy to complete on mobile, including product type, quantity, customization, sizing, deadline, and WhatsApp/contact actions.
- Add polished interactions and restrained motion, with accessible reduced-motion behavior.
- Add complete page metadata and verify the finished page across desktop and mobile.

## Assumptions
- The quotation form will open a pre-filled WhatsApp message because no inbox, phone number, or database has been supplied.
- Founder imagery will be presented as an editorial brand portrait unless actual photos are later provided.
- Contact details that were not supplied will not be invented.

## Technical Details
- Implement in the existing TanStack Start app at `/`.
- Keep brand colors and reusable visual rules in the global token system.
- Store generated imagery locally in the project and import it into the page.
